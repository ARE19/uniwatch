Local copies of the backup files the consoles make themselves (UniFi → Settings → System → Backups: automatic backups). They hold every setting including passwords and keys, can be restored in UniFi, are stored encrypted on the log server's backup disk and can only be downloaded by admins (logged in the audit log). Every backup of the last 3 months is kept (and never fewer than the newest 12 per console). Copied every Sunday 01:30 Hong Kong time, right after the consoles' weekly backup (set it in UniFi: Settings → System → Backups → weekly, Sunday 01:00), with a catch-up check every 6 hours. Only consoles reachable on the server's local network can be copied: through UniFi Site Manager the file download times out.

Each console's configuration (networks & VPN, Wi-Fi, firewall policies, zones and groups, port forwards, NAT, routes, traffic rules, switch port profiles, RADIUS, dynamic DNS, site settings) is read every 3 hours through UniFi Site Manager; a new version is kept only when something changed. Passwords, pre-shared keys, certificates' private keys and tokens are never stored: they show as "secret changed". "Seen" is when the backup noticed the change (within 3 hours of it); the admin comes from the gateway's own change log around that time.
